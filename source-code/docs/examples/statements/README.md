# Example statement folders (fictional)

Copy any of these into `statements/`, rename the folder, and edit `account.yaml` for your own
account. Then drop your real statements in (they stay git-ignored). See
[`statements/README.md`](../../../statements/README.md) for every option.

| Folder | Shows |
| --- | --- |
| `example-bank-visa/` | A credit card with monthly PDF statements (`YYYY/YYYY-MM.pdf`). Marked `pending: true` so this example never shows up as a real account. |
| `example-bank-chequing/` | A chequing account with a monthly CSV export, including a tiny sample CSV. |
| `example-card-yearly-ledger/` | A card whose CSV export always contains everything (`ledger: yearly`), with a sample `2026.csv`. |

All names, numbers and transactions here are made up.
