# Financials: brag

A 21-second launch video for Financials, a private household finance dashboard, made with [/brag](https://github.com/latent-spaces/brag) and hosted on GitHub Pages from the `gh-pages` branch.

Everything here comes from the app's demo mode: every name and number is fictional. The app's source and real data live elsewhere and are not in this repo.

- `brag-output/brag.mp4`: the video (poster: `brag.jpg`)
- `brag-output/share-copy.txt`: copy you can post as-is
- `brag-output/brag-plan.md`: angle and storyboard
- `brag-output/work/`: composition (`composition.html`), soundtrack generator (`music.mjs`), demo screenshots
- `site/`: the page published to `gh-pages`
